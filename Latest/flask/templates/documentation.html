CALVI Documentation

Welcome to the documentation for the bioinformatics tool CALVI. Below, you'll find information on how to use it.

1. Overview

This tool allows users to analyze protein alignments using Uniprot data. Simply enter an accession to retrieve alignment results. CALVI will try to look for default Eggnog alignments (Eukaryota).

As this taxonomic level is very broad please expect the alignments to contain gaps and be noisy. It is recommended to provide a more fine-tuned alignment (for example via ClustalOmega), as long as the sequence identifiers are uniprot accessions.

CALVI will then fetch uniprot functional annotations ('VARIANT', 'ACT_SITE' etc.) and color the alignment accordingly. The result is presented as a .svg in two versions, one with mouseover functionality and one without.

2. How to Use

To perform an alignment search, follow these steps:

  1. Enter a valid Uniprot accession in the search box.
  2. Enter a protein position.
  3. Determine the viewing range. The chosen protein position (2) will be in the center, and the number of positions selected here will be shown around this position.
  4. The number of sequences shown determines the how stretched the alignment will be. In the alignment may be 100 sequences, but only for a small subset of those will be functional information in the selected viewing range. Typically only the top 10 sequences provide useful information.
  5. The user can select how CALVI should sort the sequences. By default the sequences will be sorted by their number of functional annotations in the selected viewing range, but the user may also select a particular functional annotation type from uniprot to sort by - if available.
  6. Paste your Clustal Omega alignment in this text field. Make sure that the sequence identifiers are valid uniprot accessions.
  7. If CALVI successfully found a default eggnog alignment, check this box to use it. This will overwrite any custom alignment pasted into field (6).
  8. The user can then download the result as .svg.

4. Output


1: Legend. Circles on the alignment follow the color categories based on entry types from UniProt.
2: Protein features taken from Interpro.
3: IDs for each sequence. Where possible UniprotIDs (from the input alignment) are translated into gene names.
4: The shown starting position for each aligned sequence.
5: Sequence conservation. Corresponds to sequence identity for this position of the alignment. Note Columns of the alignment are colored based on amino acid type if the amino acid type (of the protein of interest) is more than 70 % conserved at this position.
6: Residue numbering for the protein of interest.
7: Positions clustered together with the input position (here 34) are displayed with the same color. A rectangle highlights the position of interest.
8: The shown ending position for each aligned sequence.

5. Tips & Best Practices

You can also try to submit gene names instead of uniprot accessions, such as "BRAF" or "RHOA". However, for best results, use specific accession numbers instead of gene names, as they provide more precise matches.
The mouseover function on the .svg can be used via right clicking on the result image, open image in new tab or by downloading the .svg and opening it with a browser of your choice (instead of an image modification program).
